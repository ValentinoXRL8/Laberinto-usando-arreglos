# Objetivo

Desarrollar un programa en Java que simule un laberinto en el que el jugador debe encontrar la salida. El proyecto busca aplicar conceptos de programación como matrices, lógica condicional, datos abstractos y, opcionalmente, recursividad.

# Instrucciones

En equipos (2 o 3 personas), desarrollar un programa en Java tomando en cuenta las siguientes reglas:

- El laberinto debe representarse mediante una matriz bidimensional de tipo `char`.
- El jugador inicia en una posición fija y debe encontrar la salida ubicada en otra celda.
- El sistema debe mostrar el recorrido, contar los pasos y mostrar si se logró salir del laberinto.
- Se permite el uso de ciclos (`for`, `while`) y estructuras básicas como arreglos.
- Extras creativos (opcionales): implementar la exploración del laberinto usando **recursividad** en lugar de ciclos. Agregar más elementos al laberinto (premios, enemigos, dar/quitar puntos, etc.)
- No se permite el uso de librerías externas ni estructuras avanzadas como listas, mapas o clases de colección.

# Entregables

1. Documento PDF que contenga:
   - Explicación breve del problema y de la solución.
   - Diseño del laberinto: cómo se representa y cómo se genera.
   - Pseudocódigo del algoritmo principal.
   - Código fuente funcional explicado.
   - Explicación del recorrido del jugador y cómo se determina si llega a la salida.
   - (Opcional) Explicación detallada del uso de recursividad: caso base, llamada recursiva, evolución de variables.
   - Ejemplos de ejecución con capturas de pantalla.
   - Conclusión: retos enfrentados, decisiones tomadas, aprendizajes obtenidos.

# Evaluación

- Diseño y generación del laberinto: 30
- Lógica de recorrido y detección de salida: 30
- Código funcional: 10
- Documentación: 20
- Uso de recursividad (extra creativo): 5
- Cualquier otro extra creativo: 5
